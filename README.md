# HabitTracker
A browser-based daily habit tracking app built with vanilla HTML, CSS, and JavaScript. Add habits, mark them done each day, watch your streaks grow and filter by category — all without a server or framework.

##Features
##Core

Add a habit — name, weekly target, and category
Inline form validation — clear error messages, no alert() popups
Habit list — renders entirely from a JavaScript array
Mark done — checkbox increments the streak
Delete — removes a habit instantly
Summary bar — total habits, done today and completion percentage with an animated progress bar

##Project Structure
habit-tracker/
├── index.html   — Page structure and markup only
├── styles.css   — All visual styles, tokens, animations, responsive rules
└── app.js       — All JavaScript: state, functions and event listeners

##Technologies Used
HTML5 – Structure and layout.
CSS3 – Styling and responsive design.
JavaScript (ES6) – Application logic and DOM manipulation.
Git & GitHub – Version control and project hosting.

##Usage
Enter the habit name.
Specify the target frequency.
Select a category.
Click the Add Habit button.
The new habit will appear in the habit list.
