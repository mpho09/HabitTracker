# Habit Tracker

A simple and user-friendly web application that helps users build positive routines by tracking their daily habits. Users can add, categorize, and monitor habits while keeping track of their progress over time.

---

## Project Overview

The Habit Tracker is designed to encourage consistency and productivity by allowing users to create habits and manage them in one place. The application provides an easy-to-use interface where habits can be added, viewed, and organized according to different categories.

This project demonstrates the use of HTML, CSS, and JavaScript for building an interactive front-end application.

---

## Features

* Add new habits.
* Categorize habits (e.g., Health, Fitness, Study, Work).
* Set a target frequency for each habit.
* Display a list of all created habits.
* Form validation with error messages.
* Responsive and clean user interface.
* Dynamic habit rendering using JavaScript.

## Getting Started

### Prerequisites

You only need a modern web browser such as:

* Google Chrome
* Mozilla Firefox
* Microsoft Edge
* Safari



---

##  Usage

1. Enter the habit name.
2. Specify the target frequency.
3. Select a category.
4. Click the **Add Habit** button.
5. The new habit will appear in the habit list.

If any required field is left empty, an error message will be displayed.
